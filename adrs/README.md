# Architectural Decision Records (org-wide)

Decisions that apply across Big Health engineering teams. Project-specific decisions live in `[project]/doc/adrs/`.

## Format

[MADR](https://adr.github.io/madr/). Use [`template.md`](template.md).

Filenames are flat numeric — `ADR-NNNN-kebab-case-title.md`. Topical organization happens in this index, not in subdirectories.

## Status legend

- **Accepted** — in effect.
- **Proposed** — under review.
- **Deprecated** — no longer applies but kept for history.
- **Superseded by ADR-NNNN** — replaced; link to the replacement.
