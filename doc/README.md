The workflow runs nightly and on changes to `config/tdd-repos.yaml`. When the registry changes, it opens a PR (`auto/tdd-registry` branch) for review and merge.

Manual edits to files in this directory will be overwritten on the next workflow run. To change the registry, change a TDD frontmatter in its origin repo, or change enrollment in `config/tdd-repos.yaml`.
