## Adding an overview

1. Open a Draft PR with the new overview file.
2. Add a row to the index above with your name as owner and today's date as last-reviewed.
3. Follow the documentation PR workflow in [`../CONTRIBUTING.md`](../CONTRIBUTING.md).

## Review cadence

Owners are responsible for reviewing their overview at least annually and updating the last-reviewed date. An overview whose last-reviewed date is more than 18 months stale is treated as unowned and subject to removal.
