# config/

Machine-readable configuration consumed by argus automation.

| File | Consumed by | Purpose |
|---|---|---|
| `tdd-repos.yaml` | `.github/workflows/regenerate-tdd-registry.yml` | List of repos enrolled in the TDD registry. |

Files in this directory are inputs to GitHub Actions and helper scripts. Edits go through the same documentation PR workflow as the rest of argus — see `process/engineering-handbook.md`.
